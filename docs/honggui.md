## 规则

- 渊启：游戏开始时可选择任意数量角色（可含自己），各获得一个渠。每回合全场使用的第一张锦囊牌结算后，其他无渠角色从当前回合角色起按行动顺序，依次选择是否交给涛至少一张手牌或装备牌；交牌后获得渠。已有渠者、无牌者跳过。渠不叠加。
- 洞深：涛的渠不能被濒死、洞深或潮蔚移除。有渠角色的手牌只对涛持续可见。在每个结束阶段，从当前回合角色起，仍有渠且本回合弃置过牌的角色依次可以移除至多 X 名角色的渠，X 为该角色本回合弃牌数。若前序结算移除了后续角色的渠，后者跳过。不能选择拥有洞深的角色。
- 潮蔚：出牌阶段整局限一次。有渠且可以移除渠的角色依次选择是否移除自己的渠；涛是主公时，由涛代替铁势力角色选择。全部选择完成后，涛可选择任意数量仍有渠的角色，各摸此刻剩余渠总数的牌；本次摸牌数固定。
- 渠：摸牌阶段多摸一张，然后将一张手牌或装备牌交给另一名有渠角色，或弃置一张牌。交出的装备牌直接置入接收者装备区（遵循本机装备区合法性与替换规则）。濒死时移除渠，洞深保护者除外。

## 与贾逵通渠兼容

使用同一个 `@@tongqu` 标记，互相认可。存在涛的对局由本拓展统一处理渠的延迟效果，拦截原版重复的摸牌、交牌、濒死效果；贾逵开局及准备阶段的通渠不受影响。没有涛的普通对局保持原版处理。

本拓展不要求启用 mobile 包；不修改官方包文件。
