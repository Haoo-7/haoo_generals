# Haoo自制武将

新月杀 FreeKill 自制武将合包，合并原 `Haoo_DIY` 与 `ts`，统一包名为 `haoo_generals`。

| 武将 | 原有 ID |
| --- | --- |
| 洪凯南 | `haoo__hongkainan` |
| 王累 | `haoo__wanglei` |
| 沈金坤 | `haoo__chenjinkun` |
| 于吉 | `ts__yuji` |
| 嵇康 | `ts__jiekang` |

保留原有武将、技能 ID、翻译、五张原画及嵇康技能的本地修订；去除王累技能中写死本机磁盘路径的临时调试日志。本次仅合包，不调整技能规则。原包没有独立音频文件。

## 安装与同步

适配迁移工程锁定的 FreeKill 0.5.25 与配套主力扩展。依赖 `utility`，于吉使用【影】，嵇康使用主力包提供的 `js__manjuan`；不作为无依赖的独立游戏发行版。

在游戏的拓展管理中添加本仓库 HTTPS 地址，或连接已启用此包的服务器，由原生包管理器下载服务器指定提交。安装目录必须为 `packages/haoo_generals`。

管理员应停用并移出原 `Haoo_DIY` 和 `ts`，只启用本包，避免相同 ID 重复注册。原生同步会停用不在服务器清单中的旧包；有本地开发修改的玩家应先备份，不能用“修复”替代备份。

同步后按游戏提示返回或重启，再连接服务器。主程序版本不一致、已有扩展的未提交修改及网络下载失败仍需分别处理。
