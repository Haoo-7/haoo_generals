## 新增四将（2026-11-09）

追加洪轨拓展的涛、南明毕、殺郭周、吾是琳，合包现共九将。保留四将原有内部 ID、技能原文、结算规则及分组；仅将模块和技能目录路径适配到 `packages/haoo_generals`，统一归入“铁群新设”。

本次一并加入涛与南明毕的两张原画；殺郭周、吾是琳暂无原画，四将均无独立语音。规则、边界行为及验收范围见 [四将说明](docs/honggui.md)。

四将已通过 Lua 5.4 语法、真实 FreeKill 类注册及现有技能逻辑回归检查；合包加载另行检查九将注册、技能 ID 和路径。游戏内与多人联机实测仍待确认，当前按好友测试版使用。

## 安装与同步

适配迁移工程锁定的 FreeKill 0.5.25 与配套主力扩展。依赖 `utility`，于吉使用【影】，嵇康使用主力包提供的 `js__manjuan`；不作为无依赖的独立游戏发行版。

新增四将还需要启用 `freekill-core`、`utility`、`gamemode`、`standard_ex`、`shzl`、`sp`、`yj`：界郭嘉依赖 `standard_ex`，兵临城下依赖 `gamemode`，吾是琳借用 `shzl` 的激昂、`standard_ex` 的急援、`sp` 的神戟与 `yj` 的权计。所有玩家与服务端须使用一致的引擎、拓展与提交。

在游戏的拓展管理中添加本仓库 HTTPS 地址，或连接已启用此包的服务器，由原生包管理器下载服务器指定提交。安装目录必须为 `packages/haoo_generals`。

管理员应停用并移出原 `Haoo_DIY` 和 `ts`，只启用本包，避免相同 ID 重复注册。此前单独安装过 `honggui` 的玩家也须先备份并停用该独立包，再启用本合包，避免四将和全局技能重复注册。原生同步会停用不在服务器清单中的旧包；有本地开发修改的玩家应先备份，不能用“修复”替代备份。

同步后按游戏提示返回或重启，再连接服务器。主程序版本不一致、已有扩展的未提交修改及网络下载失败仍需分别处理。
